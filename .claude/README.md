# Агентская система Claude Code

Справочник по агентам (subagents) и скиллам, доступным в Claude Code при работе
над этим репозиторием. Это документация текущей конфигурации сессии, а не
исполняемый код.

- `agents/` — карточки доступных subagent'ов: назначение и доступные инструменты.
- `skills/SKILLS.md` — список доступных скиллов (slash-команд) с описаниями.

## Как это использовать

- Subagent запускается через инструмент `Agent` с параметром `subagent_type`,
  равным имени файла в `agents/` (без расширения).
- Скилл вызывается через `/имя-скилла` или инструмент `Skill`.
