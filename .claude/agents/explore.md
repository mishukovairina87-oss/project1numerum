# Explore

Быстрый read-only агент для поиска по коду. Подходит для:

- поиска файлов по паттерну (например `src/components/**/*.tsx`);
- grep по символам/ключевым словам (например "API endpoints");
- ответа на вопросы "где определено X" / "какие файлы ссылаются на Y".

Не подходит для code review, аудита дизайн-документов, проверки консистентности
между файлами или открытого анализа — агент читает выдержки файлов, а не файлы
целиком, и может пропустить содержимое за пределами окна чтения.

При вызове указывайте глубину поиска: "quick" для точечного запроса, "medium"
для умеренного исследования, "very thorough" для поиска по нескольким местам
и вариантам именования.
