# general-purpose

Агент общего назначения для исследования сложных вопросов, поиска по коду и
выполнения многошаговых задач. Используется, когда нужно искать по ключевому
слову или файлу без уверенности, что нужное совпадение найдётся с первых
нескольких попыток.
