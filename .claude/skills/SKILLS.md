# Доступные скиллы

Скиллы вызываются через `/имя-скилла` или инструмент `Skill`.

| Скилл | Назначение |
|---|---|
| `session-start-hook` | Создание и настройка startup-хуков для Claude Code на web. |
| `design` | Дизайн-канвас — визуальный дизайн (мокапы UI, лендинги, постеры, флаеры) как Artifact. |
| `dataviz` | Гайдлайны перед созданием любого графика/чарта/дашборда в любом формате вывода. |
| `artifact-design` | Гайдлайны по дизайну перед написанием любого Artifact. |
| `artifact-diagramming` | Диаграммы для Artifacts: как рисовать понятные схемы. |
| `artifact-capabilities` | Runtime-возможности Artifact (данные, состояние, файлы, вопросы к Claude и т.д.). |
| `update-config` | Настройка harness Claude Code через `settings.json`: hooks, permissions, env vars. |
| `keybindings-help` | Настройка горячих клавиш `~/.claude/keybindings.json`. |
| `code-review` | Ревью текущего diff / PR / ветки на баги и упрощения с заданным уровнем усилий. |
| `simplify` | Ревью изменённого кода на переиспользование/упрощение/эффективность и применение правок. |
| `fewer-permission-prompts` | Анализ транскриптов и добавление allowlist в `.claude/settings.json`. |
| `loop` | Запуск команды/промпта на регулярный интервал или в режиме самостоятельного темпа. |
| `claude-api` | Справочник по Claude API / Anthropic SDK: модели, цены, параметры, кэширование. |
| `run` | Запуск и проверка приложения проекта (CLI, сервер, TUI, Electron, браузер). |
| `init` | Инициализация нового `CLAUDE.md` с документацией по кодовой базе. |
| `security-review` | Полный security-review незакоммиченных изменений в текущей ветке. |
| `anthropic-skills:docx` | Создание/чтение/редактирование Word-документов (.docx/.dotx). |
| `anthropic-skills:pdf` | Работа с PDF: чтение, объединение, разделение, водяные знаки, формы, OCR. |
| `anthropic-skills:pptx` | Создание/редактирование PowerPoint-презентаций (.pptx/.potx). |
| `anthropic-skills:xlsx` | Создание/редактирование таблиц (.xlsx/.xlsm/.csv/.tsv). |
| `anthropic-skills:morning` | Утренний брифинг пользователя как HTML-artifact или как повторяющаяся задача. |
| `anthropic-skills:import-memory` | Импорт экспорта памяти из другого AI-ассистента в память Claude. |
| `anthropic-skills:skill-creator` | Создание, редактирование и оценка (eval) новых скиллов. |
